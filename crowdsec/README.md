# Home Assistant App: CrowdSec

CrowdSec is a free, open-source, and collaborative Intrusion Prevention System (IPS) and Security Engine.

## About

This app runs the CrowdSec Security Engine directly on Home Assistant, inspecting logs from Home Assistant, `systemd-journald`, and reverse proxies like Caddy to detect malicious behavior, utilize community blocklists, and enforce automated remediation through bouncers and AppSec (WAF).
